# Project Status

Run `./projectctl status`. Read only the records in `project_ops/state.json` relevant to the question. Report last activity, next action, blocked tasks, any EVIDENCE DRIFT or open claims, each with its date. Never infer that something finished from elapsed time; check the artifact. Do not promote a claim from narrative alone.
